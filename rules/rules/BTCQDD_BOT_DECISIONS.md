# BTCQDD Bot 决策与规范事实 (260322_001)

本文档记录了关于 BTCQDD Bot 模式的关键决策事实。这些事实作为后续开发和任务执行的基础。

1. **取消 SE 作为产品模式**：不再将 Strategy Editor (SE) 视为最终对客的产品模式。
2. **产品名变更为 Bot Console**：保留当前的 UI 外壳，但产品定位和名称改为 Bot Console。
3. **新增 `btc_5m_ladder_bot` 主链**：在 BTCQDD 内新增 `btc_5m_ladder_bot` 作为主链，不新开独立项目。
4. **页面交互调整**：页面不再以自由代码编辑器为主，原有的代码区改造为参数配置区。
5. **工程模式与产品模式分离**：工程上继续保留 `paper-staging` 模式，但在产品层面上只强调 Bot。
6. **Live 模式后置**：Live 模式的开发与开放被后置，必须在 `paper-staging` 模式（Paper）充分验收通过后才能开放。
7. **自动验收原则**：自动验收机制采用“最小覆盖、条件启用、失败可定位”的轻量化方案。
8. **结构化日志要求**：Bot 的结构化日志被提升为一级产物，它是核心的业务输出，而不再是可选的调试输出。
