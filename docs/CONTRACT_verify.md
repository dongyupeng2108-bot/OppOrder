# 薄契约｜版本测试/保障模块

## 模块职责

- 提供横切保障：验证业务语义与契约一致性，输出可审计证据。

## 输入

- 业务接口返回、运行日志、样本数据、任务上下文与证据路径。

## 输出

- `verify_*` 断言结论、`verify_all_manual` 汇总结果、任务证据文件。

## 拥有权

- 拥有验证流程与证据组织；不拥有业务语义定义权。

## 禁止项

- 禁止以测试脚本定义或修改业务语义。
- 禁止将“脚本通过”替代“主链语义成立”的整链证据。

## 依赖接口/字段

- 依赖 `/bot/*` 契约、主链关键字段（anchor/bounds、`filled_total`、PNL 分区）与 runtime 样本。

## 对应验证入口

- `verify_all_manual` 及各单主题 `verify_*.mjs`。

## 边界补充

- 该模块是保障层；若主链口径被触碰，必须配合代码/API/runtime做整链验收。
