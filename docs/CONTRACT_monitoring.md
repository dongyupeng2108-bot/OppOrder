# 薄契约｜实时监控模块

## 模块职责

- 暴露和展示运行事实：通过 `/bot/*` API 与 UI 呈现执行与结果状态。

## 输入

- 执行引擎与结果模块输出的真值对象、日志与状态快照。

## 输出

- `/bot/status`、`/bot/context`、`/bot/orders`、可观测日志与控制台展示数据。

## 拥有权

- 拥有“对外暴露与展示”的职责；不拥有执行语义定义权。

## 禁止项

- 禁止反向定义生命周期、gate、decision、ledger 语义。
- 禁止以 UI 展示结果覆盖后端真值字段。

## 依赖接口/字段

- 依赖 `/bot/*` 接口契约与状态/结果字段映射。

## 对应验证入口

- API 契约校验、UI 对账检查、`verify_runtime_to_business_result` 的对外一致性部分。

## 边界补充

- 任何影响主链口径的监控改动，仍需整链验收，不得仅做页面可视化验收。
